# Rafin | Software Engineer Portfolio

A dynamic, glassmorphism-inspired personal portfolio showcasing my journey as a Computer Science & Engineering student at Southeast University. This repository contains the source code for my interactive web portfolio, highlighting my focus on Artificial Intelligence, Machine Learning, and Computer Networking.

## 🚀 Live Demo
[View the live portfolio here](https://rafin2312.github.io/updatePortfolio/)

## 🛠️ Tech Stack
* **Structure & Styling:** HTML5, CSS3 (CSS Variables, Flexbox, CSS Grid)
* **Interactivity:** Vanilla JavaScript (Typing effects, scroll reveals, interactive gallery lightbox)
* **Design System:** Glassmorphism UI, custom CSS animations, responsive mobile-first layout
* **Icons & Typography:** FontAwesome 6, Space Grotesk, Inter, JetBrains Mono

## ✨ Key Features
* **Interactive Canvas Background:** A futuristic, particle-based network canvas powered by JavaScript that responds to the spectrum color theme.
* **Dynamic Project Showcase:** Sections dedicated to core domains, including applied machine learning research (PlantVisionBD), networking infrastructure, and Enterprise Java systems.
* **Custom Photography Lightbox:** A built-in, responsive gallery highlighting trekking and travel photography.
* **Scroll-Triggered Animations:** Smooth, hardware-accelerated reveal animations tied to scroll depth.
* **Fully Responsive:** Adapts seamlessly from ultra-wide desktop monitors to mobile screens with a custom hamburger navigation.

## 📂 Repository Structure
* `index.html` — The main structure, styling, and JavaScript logic of the portfolio.
* `style.css` — External stylesheet for extended styling rules.
* `profile.JPG` — Main hero section profile image.
* `photo1.jpg` to `photo4.jpg` — Image assets for the photography gallery.
* `plantvisionbd-paper.pdf` — Embedded research paper documentation.
